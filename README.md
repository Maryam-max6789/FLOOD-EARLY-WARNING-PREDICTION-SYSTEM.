# FLOOD-EARLY-WARNING-PREDICTION-SYSTEM.

Predicting river water levels and forecasting hydrological flood waves using a Deep Learning LSTM neural network.

## Overview
This project uses historical streamflow and precipitation data to train a Long Short-Term Memory (LSTM) model. It forecasts future river water heights to serve as an early warning system for flood risks.

##  Key Features
* Simulates realistic rainfall spikes and river runoff time-lags.
* Cleans and scales sequential data using Pandas and Scikit-learn.
* Implements a multi-layer LSTM neural network using TensorFlow/Keras.
* Evaluates performance using Root Mean Squared Error (RMSE) and R2 scores.

##  Results
* **RMSE:** 0.212 meters
* **R2 Score:** 0.9963
